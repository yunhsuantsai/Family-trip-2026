# 2026 日本東北家族旅行｜互動行程網站

2026/10/21–10/28 日本東北家族旅行行程網站（Mobile First），提供八天總覽、每日時間軸、地點與 Google Maps 導航、雨天備案。

## 開啟網站

啟用 GitHub Pages 後，網站位址會是：

https://yunhsuantsai.github.io/Family-trip-2026/

## 專案檔案

- `index.html`：可直接執行的互動行程網站，不需要安裝依賴或打包工具。
- `.nojekyll`：讓 GitHub Pages 直接提供靜態檔案。

## 更新流程

編輯或透過 ChatGPT GitHub MCP 更新 `index.html`，提交到 `main` 分支後，由 GitHub Pages 自動發布。

## 發布設定

GitHub Repository → **Settings** → **Pages** → **Build and deployment** → **Deploy from a branch** → **main / (root)** → **Save**。

## 隱私提醒

- 這是公開網址，取得連結者可閱讀頁面內容，且公開 Repository 的原始碼也可以被查看。
- 站內設置 `noindex, nofollow, noarchive, nosnippet`，要求遵守規則的搜尋引擎不要索引，但**不等於密碼保護或禁止分享**。
- 請勿上傳訂位代碼、個人證件、電話、個人帳戶或其他私人資訊。
- 旅行結束後可在 Repository 的 Pages 設定中取消發布。
